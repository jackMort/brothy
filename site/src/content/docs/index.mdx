## Install

macOS or Linux, in a terminal with true color and Unicode.

<Tabs>
  <TabItem label="curl">
    ```sh
    # pick your platform: linux | darwin, x64 | arm64
    curl -fLo brothy https://github.com/jackMort/brothy/releases/latest/download/brothy-linux-x64
    chmod +x brothy && mv brothy ~/.local/bin/brothy
    brothy ~/notes
    ```
  </TabItem>
  <TabItem label="binary">
    ```sh
    # download brothy-<os>-<arch> and SHA256SUMS from the releases page, then:
    sha256sum -c --ignore-missing SHA256SUMS     # shasum -a 256 -c on macOS
    chmod +x brothy-linux-x64
    mv brothy-linux-x64 ~/.local/bin/brothy
    ```
    On macOS, clear the quarantine flag first if it is blocked: `xattr -d com.apple.quarantine brothy-darwin-arm64`.
  </TabItem>
  <TabItem label="from source">
    ```sh
    # needs Bun 1.4 or newer
    git clone https://github.com/jackMort/brothy.git && cd brothy
    bun install
    bun run build                # single binary ./brothy, parsers embedded
    ```
  </TabItem>
</Tabs>

brothy is not published to npm; releases ship prebuilt binaries only. [All install details](/brothy/getting-started/install/).

## Quick start

```sh
brothy                # browse the current folder
brothy ~/notes        # browse a folder
brothy README.md      # open one file (its folder fills the panel)
brothy -t dracula     # pick a theme (a family name opens its dark theme: -t one)
curl -s … | brothy    # read a pipe
```

Then <kbd>?</kbd> for the hints and <kbd>?</kbd> again for every key, <kbd>ctrl+p</kbd> to go anywhere, <kbd>t</kbd> for themes, <kbd>z</kbd> for zen.

## Features

<div class="two">
<div>

### Reading

- Preview and raw Source (<kbd>s</kbd>), find (<kbd>/</kbd> <kbd>n</kbd> <kbd>N</kbd>), live reload with the sections that changed listed in Info. [Reading](/brothy/usage/reading/)
- Obsidian notes: wikilinks, embeds, callouts, `==highlights==`, `%%comments%%`, dataview blocks. [Obsidian notes](/brothy/usage/obsidian-notes/)
- Zen (<kbd>z</kbd>): only the text, with scroll or pages flow, spotlight, typewriter and teleprompter. [Zen mode](/brothy/usage/zen-mode/)
- A braille minimap from 110 columns (<kbd>m</kbd>), find hits in a lane beside it.

</div>
<div>

### Navigation

- Files / Outline / Info panel (<kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd>) with fuzzy filter, folder counts and a reading marker.
- <kbd>ctrl+p</kbd> over the whole vault (notes, headings, text), with a peek pane. [Navigating notes](/brothy/usage/navigating-notes/)
- <kbd>f</kbd> labels the links on screen; <kbd>H</kbd> <kbd>L</kbd> go back and forward.
- <kbd>e</kbd> opens your `$EDITOR` at the line you are reading; `brothy -` reads a pipe.

</div>
</div>

### Looks

42 themes in 22 families, picked on a dark | light board (<kbd>t</kbd>) with a live sample note; a transparent background (<kbd>T</kbd>) and a full-width toggle (<kbd>w</kbd>). [Themes](/brothy/themes/theme-picker/)

:::tip[AI, only if you ask]
Off until you add an `ai` block. <kbd>a</kbd> streams a TL;DR into Info, <kbd>D</kbd> explains what changed on disk, `?` in <kbd>ctrl+p</kbd> asks your vault. Local models first (Ollama, LM Studio); keys from the environment only; nothing is sent on its own. [AI](/brothy/ai/setup/)
:::
