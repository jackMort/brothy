# Keybindings

## Document

1. `j` / `k` scroll one line
2. `d` / `u` scroll half a page
3. `g` / `G` jump to top or bottom
4. `[` / `]` previous and next heading

## Files

Use the arrow keys or `j`/`k`. The document follows the cursor, so you can skim a folder quickly. Press enter to move focus into the document.
